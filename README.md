# втакт

**Играть: https://ddobudko.github.io/v-takt/** — со звуком, десктоп, мышь.

Прототип концепта: ритм-игра без падающих нот. Мир дышит своим ритмом,
единственное действие — клик. Попал в фазу объекта — он вводит свой инструмент
в трек. Промах — слой глохнет, мир теряет насыщенность.

## Запуск локально

Без сборки и зависимостей:

```
cd ~/v-takt
python3 -m http.server 8123
```

Открыть http://localhost:8123/. Файл через `file://` тоже работает (обычные
`<script>`, не модули), но локальный сервер надёжнее.

Клавиши: `r` — переиграть уровень, `esc` — на титул.

## Как устроено

- `audio.js` — синтез (WebAudio, без сэмплов) и часы.
- `game.js` — сетка, уровни, ввод, отрисовка.
- `index.html` / `styles.css` — canvas + текстовый оверлей.

### Время

Ритмическая сетка живёт на часах аудиоконтекста, а не на кадрах. Наружу
`audio.js` отдаёт два времени:

- `ctxNow()` — домен планирования: нота, назначенная на `T`, слышна позже на
  величину выходной задержки;
- `now() = ctxNow() − outputLatency` — «слышимое» время.

Нота, назначенная на `T`, слышна ровно когда `now() == T`. Поэтому рендер и
оценка клика считаются в `now()`, планирование — в `ctxNow()`, и визуал, звук и
попадание сходятся в одной точке.

### Механика

У объекта есть период в долях (минимум 2), внутри цикла инструмент играет свою
фигуру — так ловить можно не чаще раза в такт, а музыка при этом плотная.
Кольцо растёт от центра и касается края ровно в момент доли; прозрачность
растёт как `phase²`, поэтому большую часть цикла объект визуально тихий.

Окна попадания фиксированы в секундах, не в долях периода: `PERFECT = 85 мс`,
`GOOD = 155 мс` (`game.js`). Клик мимо всех объектов не наказывается.

### Цвет

Насыщенность всей сцены умножается на `sync` — при рассинхроне мир уходит почти
в ч/б. Оттенок фона — круговое среднее оттенков живых слоёв, поэтому финальный
кадр уровня выглядит как «портрет» собранной аранжировки.

## Что крутить

- `BPM` в `audio.js` (сейчас 84).
- `PERFECT` / `GOOD` в `game.js` — щедрость окна.
- `LEVELS` в `game.js` — композиция уровня: `[инструмент, период в долях, x, y]`
  в виртуальном поле 1000×620.
- `INSTR[*].play(t, i)` — фигура одного цикла, `t` — абсолютное начало цикла.

На живой странице доступен `window.__VT` (`st`, `INSTR`, `LEVELS`) для подкрутки
без перезагрузки.
